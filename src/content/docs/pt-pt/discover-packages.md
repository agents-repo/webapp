## No site

1. Abra a [Home](/) para ler o que é o Agents Repo ou explorar a fatia mais descarregada.
2. Abra [Pacotes](/packages) para pesquisar, ordenar e filtrar.
3. Abra um cartão para ler a página do pacote na app.

Veja [Usar o catálogo](/docs/using-the-catalog) para detalhes da UI.

## Com a CLI

| Comando | Propósito |
| --- | --- |
| `agents-repo search <query>` | Pesquisar no índice do registry |
| `agents-repo suggest-agents` | Classificar pacotes a partir do projeto local |

## Caminho recomendado

Descobrir → avaliar na página do pacote → `agents-repo install <id>`.
