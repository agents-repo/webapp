A [Home](/) é uma landing para o usuário final: hero com busca,
blocos explicativos, quickstart CLI copiável, callout Use in chat, uma primeira fatia dos pacotes mais
baixados no último ano e um CTA curto de contribuição. Os links **Ver todos os pacotes**
vão ao índice rastreável [Pacotes](/packages).

## Busca e filtros

A busca da [Home](/) navega para [Pacotes](/packages) com a consulta na URL.
O índice [Pacotes](/packages) usa os mesmos campos de busca mais categoria e filtros estilo loja.

## Downloads e ações CLI

Os cards podem oferecer **Use in chat**, downloads diretos, **Copy CLI install** e **View**.
Para projetos reproduzíveis, fixe a CLI em `devDependencies` — veja [Instalar pacotes](/docs/installing-packages).
