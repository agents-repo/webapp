Agents Repo es el sitio público del registry abierto **agents-repo**: **agentes** y **flows** curados que puedes instalar en IDEs y runtimes de agentes compatibles.

## Qué puedes hacer aquí

1. **Explorar y buscar** el catálogo en [Inicio](/). Inicio también explica el
   proyecto, muestra un quickstart CLI copiable y lista los paquetes más descargados
   en el último año.
2. **Leer cómo está estructurado el registry** en [Cómo funciona el registry](/docs/how-the-registry-works).
3. **Instalar paquetes en tu proyecto** con la CLI — empieza en [Instalar paquetes](/docs/installing-packages).
4. **Contribuir paquetes** — consulta [Enviar un paquete](/docs/submitting-a-package).

## Destinos de instalación compatibles

Los paquetes declaran qué destinos admiten (por ejemplo GitHub Copilot, Cursor, Claude Code y OpenAI Codex). El sitio y la CLI usan los mismos identificadores. Consulta [Destinos de instalación](/docs/install-targets).
